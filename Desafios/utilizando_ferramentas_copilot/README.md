# Desafios com Python usando GitHub Copilot (inspirado em “Resolvendo Códigos”)

Este diretório reúne pequenas soluções de algoritmos em **Python**, explorando o uso do **GitHub Copilot** (ou outra IA) para:
- acelerar a escrita do código,
- melhorar legibilidade,
- testar variações e refatorações,
- documentar o raciocínio técnico.

> Observação: a proposta é seguir o **tema e o tipo de exercícios** do repositório-base, mas com organização e textos autorais (não é uma cópia do original).

---

## Como usar

Você pode executar qualquer desafio individualmente com:

```bash
python desafios/d01_concatenando_dados.py
```

Os scripts usam `input()` e imprimem o resultado no terminal.

---

## Desafios

### 1) Concatenando Dados
**Objetivo:** ler dois valores e exibir a concatenação em uma única string.  
**Conceitos:** string, entrada de dados, concatenação, formatação.

Arquivo: `desafios/d01_concatenando_dados.py`

---

### 2) Repetindo Texto
**Objetivo:** ler um texto e um número inteiro, e imprimir o texto repetido `n` vezes.  
**Conceitos:** loops, validação simples, repetição de strings.

Arquivo: `desafios/d02_repetindo_texto.py`

---

### 3) Operações Matemáticas Simples
**Objetivo:** ler dois números e um operador (+, -, *, /) e calcular o resultado.  
**Conceitos:** operadores aritméticos, condicionais, tratamento de divisão por zero.

Arquivo: `desafios/d03_operacoes_simples.py`

---

### 4) Par ou Ímpar
**Objetivo:** ler um inteiro e informar se é par ou ímpar.  
**Conceitos:** módulo (%), if/else.

Arquivo: `desafios/d04_par_ou_impar.py`

---

### 5) Média de Notas
**Objetivo:** ler 3 notas e calcular a média.  
**Conceitos:** soma, divisão, arredondamento.

Arquivo: `desafios/d05_media_notas.py`

---

### 6) Palíndromo
**Objetivo:** verificar se uma palavra/frase é palíndromo (ignorando espaços e caixa).  
**Conceitos:** manipulação de strings, normalização, slicing.

Arquivo: `desafios/d06_palindromo.py`

---

## Notas de uso do Copilot (como eu aplico aqui)

- Começo escrevendo comentários com o que o programa deve fazer (entrada/saída/regras).
- Aceito sugestões pequenas e refatoro para ficar legível.
- Peço ao Copilot alternativas (ex.: `if` vs `match`, funções auxiliares, validações).
- Reviso sempre: IA sugere, mas quem decide é o dev.
